# Noah's Detailing — "Noble & Mobile"

Marketing site for Noah's Detailing, mobile auto detailing in Harrisonburg, VA. Spec build by Lee Systems Co.

```bash
npm install
npm run dev     # http://localhost:3000
```

- Business facts: `src/site.config.ts`
- Photos: drop into `source-photos/`, then `npm run images`
- Quote form endpoint: `NEXT_PUBLIC_QUOTE_ENDPOINT`
